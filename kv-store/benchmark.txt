================================================================================
  KEY PERFORMANCE CHARACTERISTICS
================================================================================

  1. Read Path (GET):
     Store.Get → HashMap lookup → ~45ns → ~22M ops/sec
     This is a local read; no Raft consensus required.

  2. Write Path (SET):
     Client → Leader.Start() → Log Append (~2.4µs)
       → Heartbeat → AppendEntries RPC → Follower applies
       → Majority ack → CommitIndex advances → Apply to Store
     End-to-end: ~288ms (dominated by heartbeat interval)

  3. Consensus Overhead:
     RequestVote RPC: ~300ns (LocalTransport)
     AppendEntries RPC: ~434ns (LocalTransport)
     With HTTPTransport: expected ~1-5ms per RPC (localhost)

  4. Durability:
     Every committed write is fsync'd to WAL before acknowledgment.
     Group commit amortizes fsync cost under concurrent load.
